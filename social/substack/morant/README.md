2. In Substack: **New post**. Title: `The Rise and Fall of Ja Morant`. Subtitle: `A statistical account, 2017–2026.`

5. Check the two figures loaded (they come from thegravityreport.com). Settings → set the post's canonical URL to `https://thegravityreport.com/notes/morant/` if Substack offers it.
