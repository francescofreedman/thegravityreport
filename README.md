# The Gravity Report (GRAVITY)

**Game-Rate Adjusted Value, Impact, Talent, and Yield** — an independent NBA analysis
publication. One public model, every player ranked in The 644, every forecast registered
before the season and graded after.

Static site generated by small stdlib-only Python scripts, plus a Cloudflare Worker for the
API and social posting. Design "J" (locked Oct 6, 2026): white, near-black, electric blue;
Archivo + IBM Plex Mono (self-hosted).

```
content/            the source of truth: site.json, articles.json, ledger.json, the644.json,
                    pages/<slug>.json (web-edition bodies), legacy/messages.json (old inbox)
scripts/build_site.py   content/ -> every HTML page (deterministic)
scripts/make-cards.py   og:image cards (cards/*.png, players/<slug>/card.png)
scripts/check_site.py   link check + proof that article text is unchanged
scripts/build_all.sh    all of the above + the social kit index
scripts/migrate_legacy.py  one-time extraction from the inbox era (commit b18e539)
scripts/social/     make_kit.py (post kits), ledger_tracker.py (weekly tracker),
                    substack_export.py (paste-ready Substack posts), kits_index.py
social/             pipeline.js + adapters/ (Worker code: X, Bluesky, Threads, Instagram),
                    kits/ (public kit files), substack/ (paste-ready posts)
admin/              the approval page for the post queue (noindex; needs ADMIN_KEY)
assets/             site.css, fonts, small JS (filters, old-link redirects)
classic/            the original Win98 inbox, preserved as it was
notes/ the644/ players/ ledger/ model/ articles/ corrections/ data/ about/   generated pages
papers/             article PDFs + LaTeX sources (unchanged)
worker.js           /api/vote, /api/votes, /api/e (telemetry), /api/stats, /api/admin/*, cron
tests/              python3 -m unittest discover -s tests · node --test tests/pipeline.test.mjs
```

## Build and preview

```bash
sh scripts/build_all.sh
python3 -m http.server 8090
```

Then open http://localhost:8090. The API and posting queue only run on Cloudflare
(or `npx wrangler dev`).

## Two formats

- **Deep Dives** (long): LaTeX PDF + web edition, numbered (Deep Dive №N), listed in `content/articles.json` with `"format": "deep"`. Steps below.
- **Articles** (short, e.g. rapid-fire predictions): one file, `content/short/<slug>.md`, made of a JSON header between `---` lines, then `## Heading`, plain paragraphs, and `!call 25% | claim | note` lines (sources as `[n](url)`). The build makes `/articles/<slug>/` with probability bars. No LaTeX, no number.

## Publishing a new Deep Dive

Deep Dives are written for the web (no LaTeX, since Oct 20, 2026).

1. Write `content/deep/<slug>.md`. Markup: `## Heading`, plain paragraphs (`**bold**`, sources as `[n](url)`),
   `!abstract`, `!small`, `!call 55% | claim | note`, `!table Caption` followed by a pipe table,
   `!chart <id> | Caption` (data in `content/deep/<slug>.charts.json`: `type` `bars` or `dots`), and
   `!source n | title | url`. Tables and figures number themselves. Full spec: top of `scripts/deep.py`.
2. Add the article to `content/articles.json` (newest first; the first `article` entry is the homepage lead),
   with `"format": "deep"`, its number `n`, `kicker`, `dek`, `home_dek`, `lead`, `ledger` IDs and its `social` block.
   No `pdf`/`pages` needed. The page is built at `/notes/<slug>/` automatically.
3. Add its forecasts to `content/ledger.json`, the slug to the sitemap list in `scripts/build_site.py`, and an item to `feed.xml`.
4. `sh scripts/build_all.sh`, `npm test`, then `python3 scripts/social/make_kit.py article <slug>` and
   `python3 scripts/social/substack_export.py <slug>`.
5. Commit. Pushing `main` deploys (Cloudflare Workers Builds). Import the kit in `/admin/`.

Older Deep Dives №1 (Morant) and №2 (Queta) are still LaTeX PDFs with a web summary; №3–5 were converted
on Oct 20, 2026 and keep their original PDF as an archive link.

Revisions to a published article ship with a public revision note (see `/corrections/`).

## Social posting safety

Nothing posts unless `SOCIAL_DRY_RUN` is `"0"` (wrangler.jsonc vars) **and** that platform's
secrets are set **and** you approved the item in `/admin/`. Failed posts are never retried
automatically. Reddit is never automated. See `SETUP.md`.
